# Summary

This pull request adds comprehensive unit tests for Markdown report table generation in the WeighIn comment rendering module. The tests verify proper table syntax, column headers, value formatting with thousands separators, and valid Markdown pipe delimiters across different table types and scenarios.

# Problem

The comment generation module creates formatted Markdown tables summarizing resource deltas, but lacked dedicated unit tests verifying:
- Table headers are correctly rendered
- Values are formatted with thousands separators (commas)
- Tables use valid Markdown pipe delimiter syntax (`|`)
- Tables render correctly for single contract and multi-contract diff payloads
- Aggregate budgets and policy rules tables are properly formatted

# Solution

Added 6 new unit tests in `test/comment.test.ts` covering:

1. **Single contract function table** - Verifies headers (`| | Metric | Base | Head | Delta | Change | Limit |`), pipe delimiters, and comma-separated values
2. **Multi-contract diff tables** - Verifies tables render correctly for multiple contracts with proper contract labels
3. **Large number formatting** - Verifies numbers like 1,000,000 are properly formatted with thousands separators
4. **Aggregate budgets table** - Verifies the aggregate resource budgets table headers, data rows, and member breakdown table
5. **Policy rules table** - Verifies the effective policy rules table with proper markdown formatting

# Changes Made
